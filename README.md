# Objetivos do projeto-redes:
- Capturar pacotes que estão passando pela máquina
- Criar banco de dados e aramazar os pacotes rastreados
- Criar a partir do banco uma opção de gerar logs com as informações coletadas
- Criar servidor web local para que possamos umar uma página web como interface do programa além do pŕoprio terminal.
- Criar uma "interface" primitiva de terminal com o Rich
- Criar um sistema de filtros para poder gerar logs mais específicos
- Criar um sistema de filtros de captura. Ex: Filtrar por IP, Porta, Protocolo, Tamanho do pacote e etc.
- Fazer sistema que faça análise em tempo real para que o usuário possa acompanhar e possa parar ele quando achar necessário.
- Fazer com que cada pacote capturado tenha sua data e hora atribuidos a ele para facilitar identificação nos logs.
